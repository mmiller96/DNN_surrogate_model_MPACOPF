## 🧠 Project Overview

This repository contains the implementation and experiments for the paper  
**“DNN Surrogate Model for Multi-Period AC Optimal Power Flow (MP-ACOPF)”**.

The project develops a framework that replaces the full AC power flow equations  
with a **deep neural network surrogate model** inside an **MP-ACOPF** optimization.  
It integrates the surrogate into a nonlinear optimization solved with Augmented 
Lagrangian method (ALM), allowing faster yet physically consistent power grid operation.

For the complete methodology, system architecture, and mathematical formulation,  
please visit the detailed project documentation on DeepWiki:
